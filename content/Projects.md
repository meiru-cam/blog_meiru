# Projects

## [Priaxis](https://github.com/meiru-cam/Priaxis) — Autonomous Personalised Agent System
*2025 – Present*

**Challenge:** How can an LLM agent autonomously manage personal goals while adapting to individual user context without explicit instruction?

**Approach:** A multi-agent system built on the Claude Code SDK and the Model Context Protocol (MCP) for structured tool use, with personalised planning and execution grounded in user history and preferences.
