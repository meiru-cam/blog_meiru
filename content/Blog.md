## How to Create a New Blog Post

1. Create a new markdown file in the `blog/` folder
2. Add frontmatter with title, date, and tags:

```yaml
---
title: "Your Post Title"
date: 2025-10-01
tags:
  - literature-review
  - phd-life
---
```

3. Write your content in markdown
4. The post will automatically appear here and be filterable by tags!
